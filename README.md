## 💡 Executive Summary

Travelers, outdoor planners, and local operators struggle with cluttered weather sites that hide historical context behind paywalls. WeatherWatch Pro v6 solves this with a clean, dual-view weather intelligence dashboard powered by free Open-Meteo forecast and historical archive APIs, Leaflet OpenStreetMap, and zero-key reverse geocoding.

Core MVP workflow: (1) On boot, auto-detect the user's GPS location (falling back to Madrid) and resolve the real city name; (2) In Map View, click anywhere, use the top search bar, or tap quick city hubs (Madrid, Barcelona, Valencia, Sevilla) to view live temperature, feels-like, wind, humidity, and simple comparison badges vs 7, 30, and 365 days ago; (3) Switch to Analysis View for a clean 24-hour grid (no horizontal scroll) and a 7-day forecast table.
